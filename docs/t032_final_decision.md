# T-032 final decision

## Permanent stop: fresh-diversity selection

The fresh-diversity selector is permanently stopped under T-032.  The exact
finite-time oracle improves the active aggregate risk by only 0.629%, only
6/144 active cells reach 5%, and neither the message nor environment budget
ray has any positive oracle value.  The result is byte-identically
reproduced.  Gates, cells, endpoints, and thresholds must not be changed to
rescue the identifier.

The following variants are therefore not authorized as continuations of this
line:

1. a learned freshness/diversity controller;
2. a wall-clock-only reinterpretation;
3. a heteroscedastic quality selector presented as correlation adaptation;
4. a larger sampled pilot or GPU benchmark intended to manufacture power.

## ICML status

The current practical participation-selection line is below the ICML bar.
Its theory core remains potentially publishable, but another selection policy
cannot create learning value beyond the failed exact oracle ceiling.

The only retained ICML algorithmic hypothesis is **identifiable low-rank
factor correction**: replace subset selection by a low-complexity unbiased
aggregator that cancels shared Markov factors while retaining idiosyncratic
information.  This is a new hypothesis, not a rebranding of T-032.

Before any experiment identifier is opened, a new outcome-free theory audit
must establish:

1. identifiability and equal-loading impossibility;
2. the known-factor optimal linear-unbiased aggregator;
3. heterogeneous-delay factor alignment or prediction;
4. an exact finite-time Markov-SA risk and a matching estimator-class lower
   bound;
5. a low-rank complexity bound without an m-by-m covariance inverse;
6. a primary-literature novelty boundary;
7. a natural benchmark with a public common-factor mechanism.

Only if this audit passes may a new CPU static scan be preregistered.  GPU and
HPC4 remain unauthorized.
