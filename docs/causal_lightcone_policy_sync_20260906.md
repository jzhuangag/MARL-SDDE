# Causal light cones for Lyapunov-scheduled policy-version synchronization

Date: 2026-09-06

Status: unified problem formulation, proved coupling/tail lemmas, and an
executable low-complexity Lyapunov decision.  A benchmark controller is not
yet preregistered.

## 1. One research question

In asynchronous centralized training with decentralized execution (CTDE), a
rollout worker may hold a different cached version of every teammate policy.
Refreshing every policy before every rollout removes strategic staleness but
serializes training and spends quadratic communication.  Refreshing none
preserves throughput but biases an owner's policy gradient when a stale
teammate can affect the rollout's future reward.

The paper asks one question:

> Which teammate-policy versions must be fresh for the rollout that is about
> to be launched, and how should those refreshes and the eventual packet step
> be controlled under random communication and computation delays?

A directed edge `j -> i` means that the server sends the current parameter
block `theta_j` to the worker launching an owner-`i` rollout.  It is not
parameter averaging, an execution-time message, or value-factorization
message passing.  Execution after training remains decentralized and uses no
new communication.

## 2. Structural causal Markov game

Fix the launch filtration `F_k`.  Conditional on launch state `x`, unroll an
episodic Markov game for `H` steps as a structural causal model with mutually
independent exogenous transition and action noises.  Policies factor by agent,

\[
\pi_\theta(a\mid o)=\prod_{i=1}^n\pi_{i,\theta_i}(a_i\mid o_i).
\tag{1}
\]

Let `Z_i=sum_{t=0}^{H-1} grad log pi_i(A_i^t|O_i^t)` and let the discounted
return satisfy `|R_H|<=B_R`.  Assume `||Z_i||<=B_{Z,i}`.  The owner gradient
functional is

\[
G_i(\theta;x)=\mathbb E[R_H Z_i\mid X_0=x].
\tag{2}
\]

For a declared set of version edges `C(x,H)`, construct a truncated causal
model in which every policy block outside the owner cone is held at an
arbitrary reference version.  Let the true and truncated rollouts admit a
coupling that agrees in all variables entering `R_H Z_i` with probability at
least `1-delta_i(x,H)` for every cache version on the line segment being
compared.

This coupling requirement is exact in a finite-horizon factored Markov game
when the unrolled directed graph contains no path from the omitted policy
block to the owner's score/reward ancestors.  For local transition factors,
the graph can be generated by breadth-first expansion of the active factors.
For a moving interaction such as Pistonball, a conservative position--velocity
tube supplies the prospective active factors.  An approximate tube must carry
an explicit escape probability; visual proximity alone is not a certificate.

## 3. Causal-cone tail lemma

Let `theta` and `theta'` differ only in an omitted teammate block `j`.  In the
truncated model, suppose `G_i` is invariant to that block.  Then

\[
\|G_i(\theta;x)-G_i(\theta';x)\|
\le 4 B_R B_{Z,i}\,\delta_i(x,H).
\tag{3}
\]

### Proof

For either endpoint, the coupling inequality and
`||R_H Z_i||<=B_R B_{Z,i}` give

\[
\|G_i^{\rm true}(\vartheta;x)-G_i^{\rm cone}(\vartheta;x)\|
\le 2B_RB_{Z,i}\delta_i(x,H).
\tag{4}
\]

Apply (4) at `theta` and `theta'`, insert the two truncated gradients, use their
invariance to block `j`, and apply the triangle inequality.  This proves (3).
When the causal separation is exact, `delta_i=0` and the omitted version has
exactly zero finite-horizon effect on the owner gradient.

Equation (3) bounds the gradient error caused by an omitted refresh directly;
it does not divide by a small parameter displacement and therefore remains
valid for non-smooth environment dynamics.  With bounded one-step reward
`r_max` and score `g_i`, one may use
`B_R=r_max(1-gamma^H)/(1-gamma)` and `B_Z,i=H g_i`.

## 4. Dynamic-cone advantage is structural, not heuristic

Consider `m` launch states whose certified cones have disjoint edge sets
`E_1,...,E_m`, each of size `d`.  A dynamic causal scheduler that observes the
launch state needs at most `d` refreshes.  Any single static graph that has
zero cone omission error in all `m` states must contain

\[
\left|\bigcup_{z=1}^m E_z\right|=md
\tag{5}
\]

edges.  This is a set-cover identity.  Moreover, for any static graph omitting
one edge in state `z`, there is a bounded local game whose only nonzero
cross-policy gradient effect is on that edge; hence no smaller static graph
has uniform zero omission error on the class.

Thus state-conditioned scheduling has an `m`-fold communication separation on
the constructed class.  Pistonball's development audit gives the empirical
reason to test this mechanism on a standard benchmark: the high-influence
region moved from the right to the center to the left while conservative tubes
used roughly 8--19% of complete-graph edges.  That development result is not a
controller-performance theorem.

## 5. Lyapunov is the design rule

Use the four-event learning energy

\[
U_k=F(\theta^k)-F_\star+C_k+H_k,
\tag{6}
\]

where `C_k` is outgoing-cache debt and `H_k` is pending-rollout history debt.
Let the communication queue be

\[
Q_{k+1}=[Q_k+c_k-\bar c]^+.
\tag{7}
\]

At dispatch, evaluate only certified cone edges.  If refreshing edge `e`
reduces the upper drift bound by `b_e` and costs `c_e`, the separable
drift-plus-penalty minimization selects

\[
x_e^k=\mathbf 1\{Vb_e^k>Q_kc_e^k\}.
\tag{8}
\]

Under a per-launch cardinality cap, take the largest positive values of
`Vb_e-Q_kc_e`.  This is the exact minimizer, not a graph-scanning heuristic.
Its cost is `O(|C(x,H)| log |C(x,H)|)` with a cap and linear without one.

At packet receipt, let the certified scalar quadratic bound be

\[
-\alpha A_k+\frac{\Lambda_k\alpha^2}{2}B_k,
\qquad 0\le\alpha\le\bar\alpha_k.
\tag{9}
\]

The same learning Lyapunov function chooses the applied update mass

\[
\alpha_k=
\begin{cases}
\min\{\bar\alpha_k,A_k/(\Lambda_kB_k)\},&A_k>0,\ B_k>0,\\
0,&\text{otherwise}.
\end{cases}
\tag{10}
\]

Dispatch graph and receipt step are not chosen simultaneously because the
packet's delay and realized gradient are not known at launch.  Equations (8)
and (10) are nevertheless two causal minimizations of the same composite
Lyapunov drift bound.

Combining the previously proved noisy drift-comparison theorem with (3) gives

\[
\frac1K\sum_{k<K}\mathbb E[S_k]
\le
\frac{U_0+Q_0^2/(2V)}{\gamma_0K}
+\frac{B_Q}{\gamma_0V}
+\frac1{\gamma_0K}\sum_{k<K}
\mathbb E[r_k+2e_k+\varepsilon_k^{\rm cone}],
\tag{11}
\]

where each omitted-cone term is charged exactly once.  The queue cap and
`O(V/K)` pathwise average-budget error remain unchanged.  Random Markov
trajectory bias, cache age, and receipt delay enter `r_k` and `e_k`; they are
not replaced by a wall-clock-only metric.

## 6. Role of the controlled SDDE

The exact guarantee is discrete and event-time.  A controlled hybrid
stochastic delay differential equation (SDDE) may approximate phases of
policy evolution between random launch and receipt events,

\[
d\Theta_i(t)=-\alpha_i(t)G_i(\Theta(t),
\Theta(t-\tau(t)))\,dN_i(t)+\Sigma_i(t)\,dB_i(t),
\tag{12}
\]

with the cone graph controlling which delayed coordinates enter `G_i`.
Itô--Lyapunov analysis can expose delay/noise phase boundaries and guide `V`
or maximum-step scaling.  It is not a substitute for (11).  No SDDE theorem
will be claimed until a finite-horizon weak-approximation error from the event
process is proved.

## 7. Novelty boundary

- Localized actor--critic for networked systems uses fixed `k`-hop
  neighborhoods and proves an approximation that decays with radius; it does
  not schedule asynchronous teammate-policy versions under a communication
  queue ([Qu, Wierman, and Li, L4DC 2020](https://proceedings.mlr.press/v120/qu20a.html)).
- Asynchronous cooperative MARL with linear function approximation studies
  homogeneous agents learning copies of one MDP through a server, rather than
  distinct interacting policy blocks and mixed-version rollouts
  ([Min et al., ICML 2023](https://proceedings.mlr.press/v202/min23a.html)).
- Asynchronous actor--critic papers address asynchronous action or macro-action
  timing, not training-time policy-cache freshness
  ([Xiao, Tan, and Amato, NeurIPS 2022](https://papers.nips.cc/paper/2022/hash/1c153788756d35559c22d105d1182c30-Abstract-Conference.html);
  [Jung et al., ICML 2025](https://proceedings.mlr.press/v267/jung25a.html)).
- Dynamic coordination graphs and action-dependency graphs structure joint
  action selection or value representation.  The present graph carries policy
  versions between training workers and is absent at decentralized execution
  ([Siu, Traish, and Xu, ACML 2021](https://proceedings.mlr.press/v157/siu21a.html);
  [Ding, Tang, and Jing, UAI 2026](https://proceedings.mlr.press/v337/ding26a.html)).

The defensible novelty is the combination of a launch-state/horizon causal
cone, asynchronous mixed-version policy learning, and Lyapunov control of both
which version edges to refresh and how much of a returned update to apply.
Any claim that generic physical adjacency alone implies gradient sparsity, or
that return-only sensing reliably discovers the graph, is excluded by the
development audit.

## 8. Remaining theorem gates before a controller pilot

1. Instantiate a certified or explicitly assumed escape bound
   `delta_i(x,H)` for the positive task family.
2. Express the cone-refresh benefit `b_e` using centralized-critic quantities
   and bound its Markov/off-policy error uniformly over the cone.
3. Prove the launch-to-receipt bookkeeping when a refreshed packet arrives
   after additional policy changes.
4. State the comparator activation condition that makes the average remainder
   in (11) vanish or reach a declared neighborhood.
5. Freeze a controller, strong static-cone and always-fresh baselines, full
   communication accounting, seeds, and nontriviality gates before any new
   benchmark return is observed.
