# LCO-V0 value-of-information development plan

## Status

LCO-V0 is a post-failure architecture development run.  It is not a pilot,
confirmation, or formal experiment.  It uses the same permanently
development-only seeds as LCO-S0 because its purpose is to determine whether a
new controller is worth proving and confirming.  Those seeds can never be
used as independent evidence.

The LCO-S0 outcome is not reinterpreted and none of its gates are changed.
LCO-V0 removes fixed periodic probes entirely.  It tests the distinct
Lyapunov-priced dual-control rule derived in
`lyapunov_priced_dual_control_design.md`.

## Frozen algorithm and comparators

At each asynchronous coordinate event, the dual controller uses the belief
available before the event, its resource debt, and a one-step closed-form
value of the observation that would be generated by an optimistic update.  A
current fingerprint can update only the next event's belief.  Every query is
the actual optimistic update and counts against the same hard finite-horizon
allowance.

The run includes:

- the causal value-of-information controller;
- a causal myopic-belief ablation with the same filter but no information
  value;
- the exact-phase Lyapunov controller as a ceiling;
- never optimism;
- every period-four fixed mask feasible under the same budget.

The strong comparator is selected cellwise from all feasible fixed masks
using the eight development seeds.  This is intentionally a demanding
descriptive baseline, not a confirmatory estimate.

## Grid and execution

The grid contains 1,920 paths and 1,966,080 coordinate events:

- normalized steps 0.2, 0.5, 0.8;
- first-agent arrival probabilities 0.1, 0.5;
- phase persistence 0.8, 0.95;
- rotation stationary fractions 0, 0.25, 0.5, 0.75, 1;
- optimism budgets 0.25, 0.5;
- fingerprint perturbations 0, 0.05;
- eight development seeds 83,001--83,008.

The run is local CPU only with four ordered workers.  No GPU or HPC4 resource
is authorized.

## Frozen survival gates

All gates are mandatory:

1. every rate is finite and all calls are fully accounted;
2. each noise level has mean separated-dynamic gain at least 0.02;
3. each noise level captures at least 0.40 median exact-phase gain;
4. at least 75% of separated dynamic cells improve at each noise level;
5. each arrival group has mean gain at least 0.005;
6. persistence 0.8 has mean gain at least 0.01;
7. budget 0.25 has nonnegative mean gain;
8. at each noise level the dual controller beats the myopic-belief ablation by
   at least 0.002 mean log rate;
9. at least 0.1% of mixed-phase events are genuine information-induced calls;
10. stationary potential loss and hard-budget overshoot are both zero;
11. the result remains explicitly development-only.

Any failure stops this one-step dual-control architecture.  Thresholds,
seeds, or target cells must not be changed after execution.  Passing would
authorize only a Markov sensing-error theorem and a later preregistration with
new seeds; it would not authorize formal evidence or a standard MARL/GPU run.
