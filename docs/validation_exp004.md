## Validation Report

- Source: `EXP-004-stagewise-controller`
- Overall Confidence: CAUTION

The numerical experiment completed without non-finite trajectories and used
paired noise paths across policies. Confidence remains `CAUTION` because the
full same-seed reproduction did not complete and the reported bootstrap
intervals are not multiplicity-adjusted.

### Statistical findings

| Metric | Method | Value | Effect interpretation | Confidence |
|---|---|---:|---|---|
| Adaptive joint / delay-only high-correlation MSE | Paired-seed bootstrap | 0.3616, 95% interval [0.3083, 0.4208] | About 63.8% lower aggregate MSE | SOLID within this simulator |
| Adaptive joint / all-agent adaptive-step MSE | Paired-seed bootstrap | 1.0014, interval [0.9770, 1.0289] | No detectable accuracy benefit from participation adaptation | SOLID null comparison within evaluated range |
| Adaptive joint / proxy-oracle MSE | Paired-seed bootstrap | 1.2345, interval [1.1214, 1.3616] | Point estimate meets the 1.25 gate, but interval includes materially larger gaps | CAUTION |
| Participation response | Descriptive across 64 seeds | Median \(q:32\to4\) | Controller detected the server-time dependence shift | CAUTION: action changed without MSE benefit |

No p-values were used. Confidence intervals were generated by 2,000 paired
bootstrap resamples over seeds. The paired design is appropriate because every
policy receives the same Markov-noise path within a seed.

### Assumptions and warnings

| Type | Detail | Affected result |
|---|---|---|
| Estimator bias | A 20-sample batch length underestimates the theoretical long-run variance of a highly persistent AR(1) factor in finite stages | Gap to proxy oracle |
| Boundary action | The adaptive policies frequently selected the minimum step size 0.0025 | Generality of the participation comparison |
| Multiple comparisons | Six bootstrap ratios and several pre-registered criteria were examined without family-wise adjustment | Individual interval interpretation |
| Information pattern | All 32 messages were observed to estimate candidate scalar statistics | Any communication-saving claim |
| External validity | The experiment is a scalar controlled linear system | Claims about TD, deep RL, or nonlinear MARL |

### Fallacy scan

- Coverage: 11/11 fallacy types checked

| Fallacy | Severity | Finding |
|---|---|---|
| Simpson's paradox | NOTE | Server-time and sample-time results were reported separately. The delay-only improvement has the same direction in both groups; no aggregation reversal was used. |
| Ecological fallacy | NOTE | Conclusions are restricted to seed-averaged simulator performance and are not transferred to individual physical agents. |
| Berkson's paradox | NOTE | Seeds were consecutive and fixed before execution; no outcome-based seed filtering occurred. |
| Collider bias | NOTE | Policies were compared on paired exogenous noise paths without conditioning on a post-policy outcome. |
| Base-rate neglect | NOTE | No diagnostic classification probabilities or prevalence-dependent metric was used. |
| Regression to the mean | NOTE | Regime phases were fixed by update index, not selected because of extreme observed error. |
| Survivorship bias | NOTE | All 64 seeds and all policies completed with finite trajectories; no failed seed was dropped. |
| Look-elsewhere effect | CAUTION | Multiple pre-registered ratios were inspected without adjusted intervals. The primary conclusion relies on the failed intersection gate rather than selecting a favorable comparison. |
| Garden of forking paths | NOTE | Model, 64 seeds, phase boundaries, policies, thresholds, and batch size were registered before EXP-004 outputs. The later explanation involving the minimum step-size boundary is explicitly post-result interpretation. |
| Correlation implies causation | CAUTION | Policy effects are causally controlled inside the simulator, but this does not support causal claims about real MARL systems. |
| Reverse causality | NOTE | Policy actions are assigned before each stage's outcomes; reverse temporal ordering is absent in the simulator. |

### Reproducibility

- Method: intended deterministic same-seed re-run
- Verdict: CANNOT_VERIFY

The original 64-seed output is internally deterministic conditional on code,
seed, and environment. A full rerun was started with the same inputs but
reached the execution tool's 180-second hard timeout before output collection.
No partial files were produced and the experiment was not silently retried.

Eight deterministic unit tests passed, but these do not replace the required
end-to-end reproduction.

## Validation conclusion

The strongest supported EXP-004 finding is the large cost of assuming
independent-agent variance when selecting the step size. The data do not
support an additional accuracy claim for dynamic participation once a
dependence-aware scalar step size is used.
